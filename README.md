# Google-sheets-Data-entry-Form-with-Streamlit
Patient Health Record Management System

A simple and efficient Streamlit-based web application for managing patient health records.
This app allows users to input patient details, save them to Google Sheets, and view all existing records in a clean dashboard.

🚀 Features

Add new patient details through an interactive form

Mandatory field validation

Automatically checks for duplicate patient names

Saves all entries to Google Sheets using streamlit_gsheets

Displays all stored records in a table

Lightweight, fast, and easy to deploy

🛠️ Tech Stack

Python

Streamlit

Pandas

Google Sheets API (via streamlit_gsheets)
